Rust / Win32 原生的 Codex 双账号外框，适用于 Windows 10 2004 及更新版本、Windows 11 x64。

下载并完整解压 `AgentX-Windows-x64-0.5.2.zip`，双击 `AgentX.exe`。先安装官方客户端，再分别登录两个账号。运行时无需安装 Rust、Python 或 tmux。

- 单入口启动两个官方客户端，通过原生账号标签切换；各自使用独立数据目录。
- 关闭外框后客户端继续运行；重新打开时复用现有实例。
- 修复 EXE、窗口和托盘没有 AgentX 图标的问题，提供多尺寸图标。
- 双击 `创建桌面快捷方式.cmd` 创建带图标的桌面入口；更新入口时保留已有启动参数。
- 修复官方隐藏辅助窗口导致的主窗口选择和标签栏位置错误。
- 附带环境检查、窗口测试和 SHA-256 校验文件。

Windows 实机验收范围为官方登录页。登录后的双账号会话隔离、真实任务连续性、多显示器及其他缩放比例尚未验证。当前应用未做 Windows 发布签名。
