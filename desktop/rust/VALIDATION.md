## 实机发现的修复

0.5.0 将最大的候选窗口当作主窗口。官方客户端还有一个较大、隐藏、标题为空的辅助窗口，可能被选中，导致标签栏位置和窗口置前错误。仅判断前台进程 ID 无法发现这个问题。

0.5.1 要求主窗口具有标题，优先选择主窗口和可见窗口，再比较面积；启动等待也使用真实主窗口条件。原生测试新增一个比主窗口更大的隐藏无标题窗口，验证其保持隐藏。修复后重新验证了真实窗口句柄、标签栏边界和两个登录界面的截图。
